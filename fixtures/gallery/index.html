Rendering gallery

Each page isolates one thing a cell renderer can get wrong.

  • typography.html – sizes, weights, links, lists, quotes, code
  • cards.html – modern UI: shadows, radii, badges, buttons, icons
  • gradients.html – gradients, opacity, translucent overlays, borders
  • photo.html – photo, icon, SVG, image links, captions
  • video.html – a real <video>, a live canvas, a GIF-like animation
  • sticky.html – fixed header, sticky nav, cookie banner, back-to-top
  • longpage.html – 200 numbered rows for scroll testing
  • article.html – text-heavy article with sidebar, tables, code
  • dark.html – dark page (and prefers-color-scheme)
  • forms.html – every kind of control
  • motion.html – JS timers, transitions, a progress bar, a clock
  • unicode.html – CJK, emoji, RTL, combining marks
